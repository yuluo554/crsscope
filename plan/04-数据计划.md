### 1.1 生成器纪律

- 每个 fixture 目录一个 `gen.py`，**固定输入、无随机、无时间依赖**。
- `gen.py` 同时产出 `expect.json`（金标）与语料文件；`--check` 重生成并**逐字节比对**。
- **自检写在 `build()` 末尾**，不写在 `__main__` 里——
  `--check` 走的是 `build()`，写错位置等于自检在门下从没跑过。
- `--check` 的判据是**两层**：冻结产物与重生成结果字节一致 + `expect.json` 与重算值一致。

```bash
py -3.12 data/fixtures/boundary_divergence/gen.py --out data/fixtures/boundary_divergence
py -3.12 data/fixtures/boundary_divergence/gen.py --check   # exit 0 = 逐字节一致
```

### 1.2 不入仓清单

`*.geojson` / `*.gpx` / `*.kml` / `*.csv` 与 `data/fixtures/*/out/`、`data/mask/out/`
均已在 `.gitignore` 封禁。**入仓的只有 `gen.py` 与 `expect.json`**。

> ⚠️ 这条纪律有一处结构性风险：`.gitignore` 封 `*.json` 之外的文件，测试若依赖"生成物已在磁盘"
> 就会在**干净 clone** 里失败。处置 = `tests/conftest.py` 里 session 级 autouse fixture
> **缺件则先跑生成器**（M1 落位时实现），并保留"生成物不入仓"的原样。

## 二、真值纪律

| 纪律 | 落地 |
|---|---|
| **真值只存"输入 + 期望"，不存"观测"** | `expect.json` 里出现 `observed` 一类字段即视为违规（`tests/test_expect_shape.py` AST/键名断言） |
| **期望值可由输入独立复算** | 边界分歧金标由 `(lon, lat)` + 两套常数**直接代入**算出，不复用生产实现 |
| **参考实现三落点位** | ① 进包（`src/crsscope/algorithms.py`）② 不共享（测试对照实现不得 import 生产模块）③ 必被真命令读 |
| **生成期断言植入信号可检出** | `water-track` 的偏移幅度必须 ≥ 8× 距离量化噪声；`tile-flip` 的 `y` 翻转必须使覆盖集合非空 |
| **手写算术要用 stdlib 交叉证伪** | 金标里的瓦片 `y` 换算、度数—米换算全部用 `math` 全量交叉验证，不抽样 |
| **`not_converged` 也要有金标** | F1 里构造一个迭代超上限的输入，`expect.json` 里写 `not_converged` |

### 2.1 金标格式

```json
{
  "fixture": "boundary_divergence",
  "generator_version": "1",
  "cases": [
    {"id": "case-001", "lon": 73.2, "lat": 39.5,
     "coordTransform_py": "outside", "gcoord": "inside", "agree": false,
     "expected": {"boundary_table_row": {"agree": false}, "jump": true}}
  ]
}
```

- `id` 形如 `case-\d{3}`，**不出现真实地名 / 真实用户**（`data/README.md` §三.3）。
- 坐标取海洋或无人区整数/半整数点；地名只用虚构名。

## 四、掩膜计划（模块 M2）

- **首期**：`data/mask/gen.py` 生成构造网格（JSON，`cells` 按 `(lat_idx, lon_idx)` 索引，
  取值 `land` / `water` / `unknown`），步长 1°。
- **不是地理真值**：报告必须同时输出 `mask_version` 与 `mask_max_resolution_deg` 并声明一句
  "掩膜为构造低分辨率网格，非地理真值"。
- **生产口径**：用户用 `--mask <file>` 提供自己的网格；运行期**不下载**任何数据。
- **`unknown` 不计入落水分母**；海岸带单独计数（§4.3）。
- **步长 > 1° 即拒绝加载**（exit 3），不得静默降采样。
