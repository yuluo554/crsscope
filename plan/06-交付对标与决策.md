## 四、缺口

| 缺口 | 影响 | 计划 | 关闭判据 |
|---|---|---|---|
| 判定逻辑为空实现（五子命令只做参数解析与占位返回） | 评分"功能效果"全不达标 | M2–M5 逐个落位 | 各里程碑 DoD 全绿 |
| 语料与掩膜未生成 | M1–M5 无可验证输入 | 里程碑 M1 | 七份 `gen.py --check` 逐字节一致 |
| `tools/check-release.py` 未实现 | M6 无法执行发布门 | 里程碑 M6 | 三档各跑通 |
| CI 从未实跑 | "CI 绿"不可声明 | 首推后补记 run id | `gh run list` 全绿 + 留档登记 |
| 真实地理掩膜缺失 | 落水启发式只在构造网格上成立 | 二期（题面 §三 扩展项） | 用户自备 `--mask` |
| 骨架的 `detect` 尚未接掩膜 | M3 无法开工 | 随 M1 掩膜一起 | `mask.py` 加载 + 步长上限断言 |

## 五、风险登记

| 风险 | 等级 | 应对 | 检出方式 |
|---|---|---|---|
| 把 `crs` 写成 MUST NOT | **高** | 决策 ①；文案统一 "no longer used" | `tests/test_wording.py` 全仓字符串扫描（**含否定句白名单**） |
| 只引 R1 不引 R2 | **高** | 决策 ②；默认 warning | 变异靶子：删 R2 → 级别升级 → 测试必红 |
| 把 GCJ-02 逆向说成"精确还原" | **高** | 决策 ③；固定三段残差 | `residual.kind` 集合相等断言 + 禁用措辞扫描 |
| 掩膜分辨率被当真值 | 中 | §4.3 上限声明 + `unknown` 不计分母 | 报告必含 `mask_max_resolution_deg`；步长 > 1° 拒绝加载 |
| 与 Show HN 先例同质 | 中 | 决策 ⑤：CLI/CI 批量 + M1/M2/M3 差异化 | `plan/01` §七 边界逐条；不提供单文件浏览器形态 |
| 瓦片模块显弱 | 低 | 只做一个检查项，不做渲染/切片 | `plan/01` §七 边界 |
| 骨架若被当成"已完成"，后续误判进度 | **中高** | 占位返回必须**显式**报"未实现"并以 exit 3 退出，**不得**返回空结果冒充通过 | `tests/test_unimplemented_contract.py`：每个未实现子命令必须 exit 3 且 stderr 含 `not implemented` |
| 阈值在代码与文档两处漂移 | 中 | `data/README.md` §四唯一权威 | `tests/test_single_source_of_thresholds.py` |
| 干净 clone 缺生成物 | 中 | `tests/conftest.py` session autouse 补齐 | CI 首推 + 本地 `tar --exclude` 复现 |
