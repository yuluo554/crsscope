## 四、缺口

| 缺口 | 影响 | 计划 | 关闭判据 |
|---|---|---|---|
| `xdiff` / `geojson` / `tiles` / `report` 仍为占位实现（`decl` / `detect` 已落位） | 评分"功能效果"只拿到 M1 / M2 两项 | M4–M5 逐个落位 | 各里程碑 DoD 全绿 |
| `decl` 的 `unit` / `extent` 两项只有单测覆盖，**无入仓语料金标** | 两项判据的数值回归只靠临时构造样本，语料侧缺"冻结证据" | M4–M5 期间补一份 `decl_mixed` 语料（米/度混用 + 0857 声明） | 新增 fixture 的 `expect.json` 含 `unit` / `extent` 用例，`--check` 逐字节一致 |
| `detect` 的两库边界分歧只用**单点/小样本**构造样本触发（可判定点 < 30 → 一律 `undecidable`） | `boundary_profiles` 的"分歧态"缺一份 ≥ 30 点、有确定 `winner` 的入仓语料 | M4 期间补一份跨边界带的 `boundary_straddle` 语料 | 新增 fixture 的 `expect.json` 含两 profile 结论差异 + 该批 `winner` 非空 |
| `tools/check-release.py` 未实现 | M6 无法执行发布门 | 里程碑 M6 | 三档各跑通 |
| CI 从未实跑 | "CI 绿"不可声明 | 首推后补记 run id | `gh run list` 全绿 + 留档登记 |
| 真实地理掩膜缺失 | 落水启发式只在构造网格上成立 | 二期（题面 §三 扩展项） | 用户自备 `--mask` |
| 默认 1° 掩膜分辨不了 GCJ-02 位移（250–600 m ≪ 111 km） | D2 复现**不能**用默认掩膜 | 已处置：`water_track` 自带 0.0008° 构造网格（§4.3 的 1° 是上限） | `tests/test_fixtures.py::test_water_track_fixture_supports_d2_scenario` |

## 五、风险登记

| 风险 | 等级 | 应对 | 检出方式 |
|---|---|---|---|
| 把 `crs` 写成 MUST NOT | **高** | 决策 ①；文案统一 "no longer used" | `tests/test_wording.py` 全仓字符串扫描（**含否定句白名单**） |
| 只引 R1 不引 R2 | **高** | 决策 ②；默认 warning | 变异靶子：删 R2 → 级别升级 → 测试必红 |
| 把 GCJ-02 逆向说成"精确还原" | **高** | 决策 ③；固定三段残差 | `residual.kind` 集合相等断言 + 禁用措辞扫描 |
| 掩膜分辨率被当真值 | 中 | §4.3 上限声明 + `unknown` 不计分母 | 报告必含 `mask_max_resolution_deg`；步长 > 1° 拒绝加载 |
| 与 Show HN 先例同质 | 中 | 决策 ⑤：CLI/CI 批量 + M1/M2/M3 差异化 | `plan/01` §七 边界逐条；不提供单文件浏览器形态 |
| 瓦片模块显弱 | 低 | 只做一个检查项，不做渲染/切片 | `plan/01` §七 边界 |
| 骨架若被当成"已完成"，后续误判进度 | **中高** | 占位返回必须**显式**报"未实现"并以 exit 3 退出，**不得**返回空结果冒充通过 | `tests/test_unimplemented_contract.py`：每个未实现子命令必须 exit 3 且 stderr 含 `not implemented` |
| 阈值在代码与文档两处漂移 | 中 | `data/README.md` §四唯一权威 | `tests/test_single_source_of_thresholds.py` |
| 干净 clone 缺生成物 | 中 | `tests/conftest.py` session autouse 补齐 | CI 首推 + 本地 `tar --exclude` 复现 |

## 六、与题面的口径差异（如有，必须显式登记）

| 题面口径 | 本仓落法 | 差异与理由 |
|---|---|---|
| §八 目录树列 `data/fixtures/**`（生成器 + 金标 JSON） | `data/fixtures/<name>/gen.py` + `expect.json` | 同义，<name> 用下划线（F1–F7 见 `plan/04` §一） |
| §八 掩膜 `data/mask/`（生成脚本 + 网格） | `data/mask/gen.py` + `out/`（`out/` 不入仓） | 生成物入 `.gitignore`；`gen.py --check` 可重建 |
| §四.3 "同一点四坐标系版本" 的 BD-09 / WebMercator 表示 | 由 `algorithms.py` 的前向实现生成 | **前向**变换不是本工具的产品能力（不提供 `convert`），只在 fixture 生成器中用 |
| `plan/04` §四 "首期掩膜步长 1°" | 默认网格 `data/mask/out/mask_v1.json` 用 1°；`water_track` fixture **自带**一张 0.0008° 构造网格 | §4.3 的 1° 是**上限**（`MAX_RESOLUTION_DEG`），更细合法。理由：250–600 m 的 GCJ 位移在 1° 格（≈111 km）里跨不过格线，D2 场景无法复现。默认网格仍是 1° |

> 无其他偏离。任何新增偏离必须先在本表登记，再改实现。
