## 一、分层架构

```
                ┌────────────────────────────────────────────┐
   CLI 层        │ cli.py  ─ 参数解析 / 子命令分派 / 退出码映射 │
                └───────────────┬────────────────────────────┘
                                │ 只调 report 与五命令模块
        ┌───────────────────────┼────────────────────────────┐
   子命令层  decl  detect  xdiff  geojson  tiles   （各自只做"装配 + 判定编排"）
        └───────────────────────┼────────────────────────────┘
                                │
   ┌────────────────────────────┼──────────────────────────────┐
   │ report.py  报告组装（JSON + Markdown 双轨、字段白名单）      │
   │ errors.py  错误类型 → 退出码（唯一映射）                    │
   └────────────────────────────┼──────────────────────────────┘
                                │ 共享层（**无反向依赖**）
   ┌──────────┬──────────────┬──┴──────────┬───────────────────┐
   │ geodesy  │ algorithms   │ mask        │ io（读取/解析）      │
   │ 距离/角度 │ GCJ/BD/3857  │ 离线掩膜     │ GeoJSON/GPX/CSV     │
   └──────────┴──────────────┴─────────────┴───────────────────┘
```

### 1.1 依赖方向（硬约束，AST 守门）

```
cli → {report, decl, detect, xdiff, geojson, tiles}
decl/detect/xdiff/geojson/tiles → {report, errors, geodesy, algorithms, mask, io}
report → {errors, geodesy}
geodesy / algorithms / mask / io → 只依赖标准库
```

- **共享层不得 import 任何子命令模块**（反向依赖 = 判定口径会被子命令污染）。
- **`geodesy.py` 是角度 ↔ 距离换算的唯一实现处**（`data/README.md` §4.4）。
  其他模块**一律调它**，不得自己写 haversine。
- **`algorithms.py` 是 GCJ-02 / BD-09 / WebMercator 常数的唯一落点**，
  常数与两套 `out_of_china` 边界原样照录并注明来源（`data/README.md` §1.3）。

### 1.2 为什么这样分

| 层 | 原因 |
|---|---|
| 共享层不碰 CLI | 基准/测试要能直接喂常数与坐标，不经 argparse（`argparse` 对未知参数是 `SystemExit(2)`，会把"口径错"伪装成"用法错"） |
| 一个子命令一个文件 | 五模块的判定顺序各自独立；放一起会让"判定顺序固定"这条纪律无处落 |
| `report.py` 单独一层 | 机读与人读**必须同源**（同一份结果对象渲染两次），否则两轨会漂 |
| `errors.py` 唯一退出码映射 | `data/README.md` §4.9 的优先级 `2→3→4→5→1→0` 只准写一处 |

## 二、技术选型

| 项 | 选择 | 理由 | 弃选 |
|---|---|---|---|
| 语言/运行时 | **Python 3.11+**（题面要求）；本机实测 3.8 / 3.12 两通道，CI 跑 3.11 + 3.12 | 标准库够用；`tomllib`（3.11+）可读配置 | 3.8：题面明写 3.11+，且 `itertools.batched` 等需要下限 |
| 第三方依赖 | **零运行时依赖**（stdlib only） | 与"可 CI、可断网"一致；`pip install -e .` 后无需联网装依赖 | shapely / pyproj：引入即违背"不联网、纯本地"的轻量定位 |
| 打包 | `pyproject.toml` + setuptools，`src/` 布局，`[project.scripts] crsscope` | 标准、可 `pip install -e .` | Poetry：多一层锁文件，对零依赖项目是负担 |
| 测试 | `pytest`（dev extra） + 标准库 `unittest` 兜底 | 项目无三方运行时依赖，测试只多一个 dev 依赖 | — |
| 数据格式 | GeoJSON / GPX / CSV / `.prj` / JSON 掩膜 | 题面 §三 输入面 | 引入 shapefile 解析库（超范围） |
| 输出 | `report.json`（机器）+ `report.md`（人读），同一结果对象渲染 | 双跑逐字节一致可断言 | 只输出 JSON（人读门槛过高） |
| 地图/渲染 | **不做** | 题面 §七 边界 | 任何 canvas / SVG / 图片输出 |
| 时间 | 只用 `SOURCE_DATE_EPOCH` 或固定值填 `generated_at` | 题面"不读系统时钟做判定" | `datetime.now()` |

## 三、构建与安装

```bash
# 开发安装（可编辑）
py -3.12 -m pip install -e ".[dev]"
crsscope --help

# 构建产物（M6 发布前）
py -3.12 -m build
```

- `src/` 布局：`import crsscope` 不会误取仓库根的同名目录。
- **版本唯一定义处 = `src/crsscope/__init__.py` 的 `__version__`**；
  `pyproject.toml` 用 `dynamic = ["version"]` + `[tool.setuptools.dynamic]` 读取它。
  两处不一致会被 `tests/test_version.py` 咬住（不靠手抄）。
- **零运行时依赖**：`[project] dependencies = []` 是承诺，`tests/test_no_third_party.py`
  用 AST 扫全仓 `import`，只允许标准库 + 本包。

## 四、确定性设计（贯穿所有层）

| 机制 | 落点 |
|---|---|
| 不读时钟 | 只有一个入口能取时间：`report.build_header(generated_at=...)`；默认 `SOURCE_DATE_EPOCH`，无则固定 `1970-01-01T00:00:00Z` |
| 不联网 | 全仓无 `http` / `urllib.request` / `socket` import（AST 守门） |
| 不随机 | 无 `random` / `secrets` import（AST 守门）；fixture 生成器同理 |
| 字典键序 | `sort_keys=True` 统一在 `report.dumps_json()` 一处 |
| 浮点格式化 | 一处：`report.fmt_float()`（0.1 m / 6 位小数），其余模块返回 `float` 原始值 |
| 不含主机信息 | `report.py` 输出前对绝对路径 / 用户名 / 主机名做 scrub（`tests/test_report_scrub.py`） |

**双跑一致**的判据 = 同一输入跑两次，`report.json` / `report.md` 逐字节相等（`tests/test_determinism.py`）。

## 五、交付面与非交付面（发布期口径）

| 面 | 路径 | tag 后是否可改 |
|---|---|---|
| **交付面** | `src/`、`data/fixtures/**/gen.py`、`data/mask/gen.py`、`pyproject.toml` | ❌ 零差异 |
